# 🌙 OvulAI — PCOS Cycle & Ovulation Intelligence Engine

> **Part of the Oviora AI Platform** — `models/02_cycle_intelligence_engine`

A production-grade AI engine for PCOS menstrual cycle forecasting, ovulation prediction, and clinical decision support. Built on a **Stacked Ensemble** of XGBoost, LightGBM, and CatBoost with SHAP explainability, risk stratification, and an evidence-based recommendation engine.

---

## 📊 Benchmark Results (5-Fold Cross-Validation, 9 Models)

| Model | MAE ↓ | RMSE ↓ | R² ↑ |
|---|---|---|---|

```
  │  ┌────────┐ ┌────────┐ ┌─────┐ │
  │  │XGBoost │ │LightGBM│ │ CB  │ │  ← Optuna hyperparameter tuning
  │  └────────┘ └────────┘ └─────┘ │
  └───────┬─────────────────────────┘
          │
  ┌───────┴────────────┐
  │ Ridge Meta-Learner │  ← Stacked Ensemble
  └───────┬────────────┘
          │
  ┌───────┴───────────────────────────────┐
  │         Intelligence Layers           │
  │  • Risk Stratification                │

  ┌───────┴──────┐
  │  REST API    │  ← Flask · Port 5050
  └──────────────┘
```

## 📦 Features

- **49 temporal features**: rolling stats, lag, diff, IQR, skewness, kurtosis, EMA, trend slope
- **Optuna hyperparameter tuning**: 100 trials per model
- **Stacked Ensemble**: XGBoost + LightGBM + CatBoost → Ridge meta-learner
- **SHAP explainability**: local feature contributions per prediction
- **Risk stratification**: Regular / Slightly Irregular / Irregular / Highly Irregular
- **Clinical recommendations**: PCOS-aware, sleep- and stress-sensitive
- **"Why this prediction?" narrative**: plain-English SHAP explanation
- **REST API**: ready for frontend integration with CORS support

## ⚡ Quick Start

### 1. Install dependencies

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Configure dataset paths

Edit `config.py`:
```python
PERIOD_LOG_PATH  = "path/to/Period_Log.csv"
PROFILE_PATH     = "path/to/User_Profile.csv"
```

### 3. Run the full pipeline

```bash
# Step 1 — Feature engineering + 5-fold split
python v2_01_data_pipeline.py

# Step 2 — Benchmark all 9 models + Optuna tuning (saves ensemble)
python v2_06_benchmark.py

# Step 3 — Demo inference
python v2_05_predict.py

# Step 4 — Start the REST API
python api.py
```

## 🌐 API Reference

**Base URL:** `http://localhost:5050`

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/health` | Liveness check |
